# 测试范围与兼容性

当前发布：GitHub 测试版 `v2.2.4-beta.1`，App 内版本2.2.4 (11)。

- 编译目标：Apple Silicon / arm64，最低macOS14；当前未发布Intel构建。
- 实际验收：开发机和LG TV SSCR2的单屏往返切换已由用户确认出画面。部分记录使用3840×2160、120Hz、HDR组合；此结果不适用于所有Mac、转接器和显示器。
- 镜像/扩展：提供实现和模型/模拟后端检查；当前镜像新实现尚未完成物理双屏验收。
- 未完成：其他Mac的干净首次安装、所有品牌显示器、所有macOS版本和系统更新后的完整兼容验收。
- 签名：当前是ad hoc本地签名，未做Developer ID签名或Apple公证。系统默认安全评估会拒绝自动放行。

屏幕启停和HDR涉及部分非公开系统接口，系统升级可能影响行为。输出模式仍受Mac、接口、连接设备和显示器限制。该工具不控制电视物理输入源或电源，不更改系统全局睡眠配置。

提交兼容反馈时，请提供Mac型号、macOS版本、显示器型号、连接方式、开合盖动作和实际结果。显示异常时，先开盖并使用“恢复所有显示器并暂停”。
