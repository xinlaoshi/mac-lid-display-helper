# 隐私说明

当前版本不需要注册账号，不包含广告、遥测、应用内支付或 App 联网服务。

为识别并恢复屏幕，本地设置与恢复记录包含显示器系统名称、UUID、系统提供的厂商/产品/序列号、显示模式、规则，以及恢复所需的登录会话信息。运行日志记录切换时间、设备名称、状态与错误。

数据仅保存在当前 Mac 用户目录：

- `~/Library/Application Support/LGLidSwitch/`：设置、被停用屏幕和恢复记录。
- `~/Library/Logs/LGLidSwitch/`：当前与轮换日志。
- `~/Library/LaunchAgents/com.xiaopomao.LGLidSwitch.plist`：开启“登录后启动”时创建的启动项。

2.2.7起内部名称为MacDisplaySwitch；上述历史目录与启动项标识继续保留，以兼容已有设置。首次打开升级后的App会更新同一启动项的可执行路径。

下载包不附带开发者个人设置、日志或设备列表。项目不会自动上传上述数据；主动向 Issues 提交诊断记录前，请先检查设备标识和不想公开的信息。

“关于”中的官网、GitHub与MIT协议链接只在主动点击时使用默认浏览器打开；公众号与赞赏二维码从本地资源显示。访问外部站点或使用微信扫码时，适用对应服务的规则。

本说明描述 App 本身；GitHub 下载服务及 macOS 自身的安全检查适用各自的规则。
