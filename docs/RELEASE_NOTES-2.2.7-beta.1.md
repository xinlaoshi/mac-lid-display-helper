# v2.2.7-beta.1 测试版（App 2.2.7 / build14）

本次统一内部名称并完成公开分发所需的签名与公证。

- 内部产品、归档Scheme和可执行文件名称统一为`MacDisplaySwitch`；对外名称仍为“Mac合盖和显示器联动助手”。
- App使用Developer ID Application签名，通过Apple公证并附带公证票据。最终App的严格签名、票据、Gatekeeper和分发预检均已通过。
- 沿用现有显示规则、设置目录和登录启动项标识。首次手动打开新版时，将同一App已有登录启动项的执行路径更新为新名称。
- 开发安装脚本替换完整App包，避免旧可执行文件残留；替换失败时恢复原App。
- 保持免费、公开源码、MIT许可；沿用原有菜单栏图标、关于界面和显示切换功能。

下载`MacDisplaySwitch-2.2.7-AppleSilicon.dmg`，将App拖入Applications；也提供ZIP和`SHA256SUMS.txt`。DMG和ZIP包含同一份已签名、公证并附带票据的App。系统验证时的签名开发者名称为`jinzhi zhu`。

升级前保存设置，选择“退出并恢复显示器”，替换App后，从“应用程序”手动打开新版一次。首次下载仍可能出现正常的互联网下载确认，确认来源后点击“打开”即可，通常无需去系统设置手动放行。

验证：M1 Pro对源码提交`ac277db`完成独立审查、83项引擎回归、登录启动路径升级检查和arm64构建；本机另验证了完整App替换与失败回滚。最终ZIP经SHA256核对后，在M1 Pro上解压并添加隔离标记，签名、票据、Gatekeeper、分发预检及只读状态查询均通过。本机验证了DMG和ZIP中App的一致性。镜像/扩展的物理双屏完整验收仍待补充，其他Mac干净首次启动尚未完成。
