# v2.2.4-beta.1 测试版（App 2.2.4 / build11）

自动按 MacBook 开合盖状态切换显示器的菜单栏工具。

- 开盖：只用 Mac、只用外接屏，或同时使用。
- 同时使用：镜像或扩展，扩展可选主显示器。
- 合盖：只用选中的外接屏。
- 可保存分辨率、刷新率、HDR 与切换延时，支持登录后启动。
- 本版调整菜单栏图标：外接显示器更大，并更靠近开盖 Mac。

下载 `MacLidDisplayHelper-2.2.4-AppleSilicon.dmg`，打开后将 App 拖入 Applications。

要求：Apple 芯片 Mac，macOS 14+。Intel Mac 不适用。

本包与开发机当前安装的 2.2.4(11) 一致，尚未经过 Developer ID 签名和 Apple 公证。它是测试分发包，首次打开可能被系统阻止；参阅 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

不同屏幕和转接设备的可用输出模式可能不同。部分控制使用非公开系统接口；跨 Mac 首次安装与物理镜像验收仍待补充。

若显示异常，打开 Mac 上盖，并使用菜单栏“恢复所有显示器并暂停”。
