# v2.2.5-beta.1 测试版（App 2.2.5 / build12）

新增“关于”窗口，方便查看项目信息与联系开发者：

- 菜单栏“关于…”及“使用帮助”中的“关于…”均可打开。
- 展示当前版本、MIT协议、GitHub和小破猫官网。
- 加入殇小辛公众号及自愿赞赏二维码，点击可放大。
- 赞赏图替换为殇小辛原头像与“殇小辛 的赞赏码”，二维码码点保持原样。
- 修正连接状态窗口仍显示旧版号的问题，统一读取App实际版本。

安装：下载 `MacLidDisplayHelper-2.2.5-AppleSilicon.dmg`，打开后将App拖入Applications；也提供ZIP与SHA256SUMS.txt。

要求：Apple芯片Mac、macOS14+。自动联动面向MacBook。当前是ad hoc本地签名，尚未Developer ID签名或Apple公证，首次打开可能被系统阻止；参阅[Apple官方说明](https://support.apple.com/zh-cn/102445)。

本版不更改显示切换实现。其他Mac首次安装与物理镜像/扩展的完整验收仍待补充；输出模式受硬件与连接设备限制。使用说明见[安装与使用](https://github.com/xinlaoshi/mac-lid-display-helper/blob/main/docs/installation.md)。

软件免费，采用MIT开源。赞赏完全自愿，不影响功能使用。
