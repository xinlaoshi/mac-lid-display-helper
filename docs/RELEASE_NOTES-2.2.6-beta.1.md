# v2.2.6-beta.1 测试版（App 2.2.6 / build13）

重新设计“关于”窗口，采用作者主页布局：

- 左侧显示殇小辛头像与作者介绍；右侧分为“关于软件”“公众号”“赞赏支持”三个页签。
- 软件信息集中显示版本与MIT许可，保留小破猫官网和GitHub入口。
- 公众号、赞赏二维码按需查看，点击可放大，支持按Esc或“完成”返回。
- 窗口更紧凑，保留系统原生控件并适配浅色和深色外观。

软件继续免费，采用MIT协议开源。赞赏完全自愿，不影响功能使用。

安装：下载 `MacLidDisplayHelper-2.2.6-AppleSilicon.dmg`，打开后将App拖入Applications；也提供ZIP与SHA256SUMS.txt。已有设置和登录启动偏好保留。

要求：Apple芯片Mac、macOS14+，自动联动面向MacBook。当前是ad hoc本地签名，尚未Developer ID签名或Apple公证，首次打开可能被系统阻止；参阅[Apple官方说明](https://support.apple.com/zh-cn/102445)。

本版只调整关于界面及展示资源，不更改显示切换引擎、规则或菜单栏图标。其他Mac首次安装与物理镜像/扩展完整验收仍待补充；输出模式受硬件与连接设备限制。使用说明见[安装与使用](https://github.com/xinlaoshi/mac-lid-display-helper/blob/main/docs/installation.md)。
